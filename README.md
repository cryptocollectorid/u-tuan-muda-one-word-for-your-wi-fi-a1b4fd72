## The entry

One word describing my Wi-Fi: **Ghosting**

Home Wi-Fi ghosts you — full bars one second, gone the next, right in the
middle of the call that mattered. Funny at once, true to how it actually
behaves, and it even works as a network name.

## How it works

`main.py` prints the word and writes exactly that one word to
`/output/entry.txt` (8 characters, gate: 1–20 UTF-8 characters).

```sh
python3 main.py
```
